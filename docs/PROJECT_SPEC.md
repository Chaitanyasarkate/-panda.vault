Project: VaultX

Type:
Zero-knowledge web password manager.

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- Python
- FastAPI
- SQLAlchemy

Database:
- PostgreSQL

Security:
- Client-side encryption
- Argon2id for password-derived keys
- AES-GCM authenticated encryption
- Web Crypto API
- WebAuthn/Passkeys

Initial features:
- User registration
- Login
- Vault
- Password CRUD
- Password generator
- Secure notes
- TOTP
- Security dashboard

Later:
- Cloud synchronization
- Browser extension
- Autofill
- Passkeys
